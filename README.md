🧟 Zombie VR – Jogo de Realidade Virtual
🎮 Sobre o Projeto

O Zombie VR é um jogo desenvolvido na Unity como parte de uma atividade acadêmica de Realidade Virtual (RV). O projeto tem como temática um cenário de sobrevivência contra zumbis, proporcionando ao jogador uma experiência imersiva por meio da utilização de óculos de Realidade Virtual.

O objetivo é explorar os recursos da tecnologia VR, permitindo que o jogador interaja com o ambiente virtual e tenha uma experiência diferenciada dentro do jogo.

🥽 Tecnologias Utilizadas
Unity: Engine utilizada para o desenvolvimento do jogo.
C#: Linguagem de programação utilizada para implementar as funcionalidades.
Realidade Virtual (VR): Tecnologia utilizada para proporcionar imersão ao jogador.
Óculos VR: Equipamento utilizado para executar e experimentar o jogo.
🧟 Tema do Jogo

O jogo apresenta uma temática de apocalipse zumbi, na qual o jogador é inserido em um ambiente virtual com a presença de zumbis.

A proposta é proporcionar uma experiência de sobrevivência e imersão, explorando as possibilidades oferecidas pela Realidade Virtual.

🎯 Objetivo da Atividade

Desenvolver um jogo utilizando a Unity e os recursos de Realidade Virtual, colocando em prática conceitos de desenvolvimento de jogos 3D, interação e imersão em ambientes virtuais.

▶️ Como Executar
Baixe ou clone este repositório.
Abra o projeto utilizando a Unity Hub.
Selecione a versão da Unity compatível com o projeto.
Configure o dispositivo e os recursos de Realidade Virtual necessários.
Execute o projeto utilizando os óculos VR compatíveis.
👨‍💻 Desenvolvimento

Projeto desenvolvido como atividade acadêmica da disciplina de Realidade Virtual (RV).
